# Getting help

| Need | Where |
|---|---|
| Learn the format | [Docs](https://tellscript.com/docs) and the [quickstart](https://tellscript.com/docs/quickstart) |
| Ask a question | [Discussions, Q&A](https://github.com/tellscript-dev/tellscript/discussions) |
| Report a bug in the tools or docs | [Issues](https://github.com/tellscript-dev/tellscript/issues/new/choose) |
| Propose a change to the format | The **Spec change** issue form |

Maintainers answer in Discussions and issues. Please do not send questions by email.
